MX Master control for macOS,
without Options+.

RatTamer speaks HID++ 2.0 directly to your Logitech mouse: every button remappable, ratchet / free-spin / SmartShift, DPI cycling, and trackpad-style smooth scrolling. Quit the app and the mouse returns to stock behavior.

macOS 14 or later · universal binary (Apple Silicon and Intel) · MIT license

What it does

  • Button remapping — keyboard shortcuts, system actions, synthetic clicks, gesture directions or DPI cycling, per button. Left/right swap happens at the device level.
  • Wheel modes — ratchet, free-spin, or SmartShift automatic with a sensitivity slider.
  • Thumb wheel — separate left and right actions, independent of the main wheel.
  • Smooth scrolling — hi-res wheel deltas read over HID++ and re-emitted as continuous pixel scroll. Nine presets from Native to Fluid; the slider snaps onto each preset as you pass it.
  • Advanced tuning — momentum decay, glide fraction, feed timing, bounce filter, direction threshold. All parameters exposed and applied live.
  • Scroll thermograph — a separate window plotting raw versus smoothed deltas.

Requirements

A regular app in your Applications folder — no helper daemons, no account. Connect through the Unifying/Bolt receiver for full HID++ support; some mice don't expose HID++ over Bluetooth. Accessibility permission is required to post events.

Getting it

The release zip contains the universal app — drag to Applications and approve Accessibility when prompted. The build is signed but not notarized, so the first launch needs the macOS approval flow described in the README. Configuration lives in ~/Library/Application Support/RatTamer/config.json.
