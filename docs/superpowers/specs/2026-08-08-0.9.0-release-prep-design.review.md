## Observações (não-bloqueantes)

### O1 — "schema v2" é simplificação

**README L93:** "(schema v2)"
**Realidade:** `Config` tem campo `version: Int`. `Config.empty()` retorna version 1; `migrateLegacy()` sobe para 2 quando há mudanças. Um config fresco (pré-migração) é version 1, não 2. A frase não é incorreta (após migração é v2), mas "schema v2" sugere um formato fixo. Inocuo — nenhum leitor técnico será enganado.
